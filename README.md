# Desktop EAS Client

An independent, cross-platform desktop utility built with Electron that monitors active National Weather Service (NWS) hazards and triggers automated multi-monitor full-screen emergency alerts.

## Features
* **Dual Location Support:** Auto-detects your region via network location or allows manual 5-digit ZIP code entry.
* **Multi-Monitor Overlays:** Instantly takes over all connected displays when a relevant warning matches your forecast zone.
* **System Tray Integration:** Runs silently in the background with startup-on-login persistence.

## Disclaimer
> *Important Notice:* This software is an independent emergency notification utility and is **not affiliated with, endorsed by, or connected to the National Weather Service (NWS)**.

## Installation
1. Go to the Releases page.
2. Download the latest `Desktop EAS Client Setup X.X.X.exe` file.
3. Run the installer (if Windows Defender shows an unrecognized app warning, click **More info** -> **Run anyway**).
